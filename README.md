# 上野動物園マップ / Ueno Zoo Map

GPSで現在地がわかる、日英対応・拡大縮小対応の園内マップです。
静的ファイルのみで構成されているため、GitHub Pagesにそのまま置けば動作します。

---

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体。地図表示・GPS・検索・言語切替・詳細表示 |
| `zoo-map.svg` | ベースマップ画像。文字は入っていない（ラベルはHTML側で描画） |
| `build_map.py` | `zoo-map.svg` を生成するスクリプト。地図を修正するときに使う |
| `vendor/leaflet/` | 地図ライブラリ Leaflet 1.9.4（同梱。CDN不要） |

---

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成する
2. このフォルダの中身をすべてアップロードする（`vendor` フォルダも忘れずに）
3. リポジトリの **Settings → Pages** で、公開元のブランチ（通常は `main`）と
   フォルダ（`/ (root)`）を指定して保存する
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開される

GitHub PagesはHTTPSで配信されるため、GPS取得（Geolocation API）はそのまま動作します。

### 手元で確認する場合

`index.html` をダブルクリックして `file://` で開くとGPSが動かないブラウザがあります。
簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 【必須】GPSキャリブレーション

イラストマップは実際の地図と縮尺・向きが一致しないため、
**「実際の緯度経度」と「地図画像上のピクセル位置」の対応づけ**が必要です。
`index.html` の `CALIBRATION` が現在は**仮の値**なので、必ず実測値に置き換えてください。

### 手順

1. 園内のできるだけ離れた2地点を選ぶ（例：正門と池之端門）
2. 現地でスマホの地図アプリなどから、その地点の緯度・経度を控える
3. `zoo-map.svg` を画像編集ソフト（Figma、Illustrator、GIMPなど）で開き、
   同じ地点が画像上のどのピクセル位置 `(x, y)` にあるかを調べる
   - 画像の左上が `(0, 0)`、右下が `(1600, 1300)` です
4. `index.html` の以下を書き換える

```js
const CALIBRATION = [
  { id:'main-gate',      lat:35.71700, lng:139.77160, x:1523, y:521 },
  { id:'ikenohata-gate', lat:35.71560, lng:139.76830, x:101,  y:977 }
];
```

### この方式の制約

2点から緯度経度を線形に換算する簡易方式です。
**地図が真北を上にして描かれている**ことを前提にしています。
自作マップを斜めに描いた場合は、3点以上を使ったアフィン変換に拡張してください。

## 地図を描き替える

`build_map.py` を編集して再生成します。

```bash
python3 build_map.py   # → zoo-map.svg を出力
```

スクリプト内の主なパーツ:

- `EAST` / `WEST` … 東園・西園の敷地の輪郭（SVGパス）
- `PATHS` … 園路のライン
- `grove()` … 樹林、`blob()` … 放飼場、`bldg()` … 建物、`pond()` … 水場、`cage()` … 大型ケージ
- `C` … 配色。凡例の色と対応しているので、変えるときは `index.html` の `#legend` も合わせて変更

画像サイズを変えた場合は `index.html` の `IMG_W` / `IMG_H` も更新してください。

## 施設・動物データを更新する

`index.html` の `AREAS` 配列を編集します。

```js
{ id:'gorilla-tiger',          // 一意のID
  x:1004, y:490,               // 地図画像上のピクセル位置
  tier:1,                      // ラベルを出しはじめるズーム段階（下記）
  theme:'forest',              // 凡例の色分け
  zone:'east',                 // east / west / both
  ja:'ゴリラ・トラのすむ森',
  en:'Gorilla & Tiger Forest',
  animals:[
    {ja:'ニシローランドゴリラ', en:'Western lowland gorilla'},
    {ja:'スマトラトラ',        en:'Sumatran tiger'}
  ],
  noteJa:'…', noteEn:'…' }
```

### tier（ラベルの表示段階）

| tier | 表示されるズーム | 想定 |
| --- | --- | --- |
| 1 | 常に表示 | 門、主要エリア |
| 2 | 中ズーム以上 | 一般のエリア |
| 3 | 高ズームのみ | 小さな施設、ランドマーク |

さらに拡大すると、各ラベルの下に動物名が最大3件まで表示されます。
検索中は、tierに関わらずヒットしたエリアが表示されます。

### theme（凡例の色分け）

`forest` / `savanna` / `water` / `rock` / `indoor` / `gate` / `landmark`

## 実装されている機能

- ピンチ・ダブルタップでの拡大縮小（SVGなので拡大しても輪郭がぼやけない）
- ズーム段階に応じたラベルの出し分け
- 日本語 / 英語の切替（地名・動物名・解説・UI文言すべて）
- 動物名での検索（「トラ」「tiger」どちらでもヒット。該当エリアを強調、他は減光）
- エリアをタップして詳細シート表示（動物名を日英併記で一覧）
- GPS現在地表示（`watchPosition` で歩行中も追従）と最寄りエリアの案内
- 凡例の表示切替、全体表示ボタン
- 初回表示言語をブラウザの言語設定から自動判定

## 注意事項

### ジャイアントパンダについて

上野動物園では、2026年1月に「シャオシャオ」「レイレイ」が中国へ返還され、
**現在ジャイアントパンダは飼育・展示されていません**。
「パンダのもり」にはレッサーパンダとキジ類が入っています。
本マップはこの状況を反映していますが、今後変わる可能性があるため
公開前に公式サイトで最新の状況をご確認ください。

### データの正確性

- 施設の座標は実際の配置を参考にした**概略**です。正確さを求める場合は現地で照合してください。
- 動物の在園状況は、工事による展示中止・個体の移動・死亡などで頻繁に変わります。
  公開・運用する場合は定期的な更新を前提にしてください。

### 著作権

`zoo-map.svg` は本プロジェクトで新規に描き起こしたものです。
公式マップの画像そのものは使用していません。
